# 先生向けセットアップと配布確認

対象はTello EDU 1台、Windows 11 x64とmacOSです。実機・ファームウェアの組合せとmacOS配布は未検証です。

1. READMEの手順でTello EDUをWi-Fiクライアントモードに設定し、IPを予約します。
2. PCを同じWi-Fiに接続し、`.env` の `TELLO_IP` または `--tello-ip` を指定して起動します。
3. ElectronアプリのUDP通信を許可します。状態は8890、映像は11111、コマンド応答は動的ローカルポートを使います。他のTelloアプリは閉じます。
4. 「ドローンに接続する」を押し、電池と地上状態を確認します。
5. 「写真の保存先」でPCのフォルダを選択します。「カメラON」でライブ映像を確認できます。「カメラOFF」で停止します。録画ファイルは作りません。
6. 撮影ブロックは新しいフレームをJPEG保存し、画面に表示します。カメラOFFでも撮影時に自動起動します。手動ONの場合はプログラム終了後もライブを続けます。自動起動の場合は終了・中止後に停止します。実行中のカメラ切替はできません。
7. シミュレーションで順番を確認し、先生が3項目をチェックして実機で飛ばします。ブロック編集後と飛行後は再確認してください。

プログラム中止は未送信の命令を捨てます。着陸は別ボタンです。通信が不明になった場合は自動再送しません。緊急停止はモーターを止めるため、飛行中は落下します。先生向け確認ダイアログから実行します。

写真一覧は直近20枚です。保存済みJPEGはPCに残ります。プロジェクトの「保存する」「開く」はバージョン1のBlockly JSONを扱い、写真を含めません。将来のバージョンは移行処理を追加するまで拒否します。

診断ログはローカルのuserData内に保存し、「先生用：診断ログを書き出す」で明示的にエクスポートできます。自動アップロードはありません。

## 配布

- `npm run dist:pilot`: 監督者向け試験配布。署名情報がなければ未署名です。
- `npm run dist:production`: 署名用の`CSC_LINK`と`CSC_KEY_PASSWORD`を必須にします。macOSでは`APPLE_ID`・`APPLE_APP_SPECIFIC_PASSWORD`・`APPLE_TEAM_ID`も必須にし、公証を有効にします。資格情報はリポジトリに保存しません。
- FFmpegをアプリ内に同梱するため、インストール・ビルドにはインターネットが必要ですが実行時のダウンロードはありません。対象OS上で依存関係をインストールしてビルドしてください。
- 配布時は同梱FFmpegバイナリのライセンス・ソース提供条件を確認し、必要な告知とソース案内を添付してください。
